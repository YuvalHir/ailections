## ❓ למה AIlections?

השם **AIlections** נולד מחיבור בין המילים **AI** (בינה מלאכותית) ו-**Elections** (בחירות). 
הפרויקט הינו ניסוי מחשבתי ואסטרטגי שנועד לבחון כיצד מודלי השפה המובילים בעולם תופסים את אתגרי היסוד של מדינת ישראל בבחירות 2026, ואיזו מדיניות אופרטיבית הם מציעים כאשר מטילים עליהם לבנות את **"ראש הממשלה האידיאלי"**.

---

## 🎯 מטרת הפרויקט

העברנו ל-7 מודלי AI מתקדמים את אותה משימת כתיבה יצירתית ואסטרטגית ([prompt.txt](./prompt.txt)), ללא תכתיבים פוליטיים ומתוך אילוצי מציאות קשיחים (גירעון תקציבי, זינוק בהוצאות הביטחון, שחיקת המילואים, איומים אזוריים ומבנה מערכת המשפט).

כל מודל נדרש לגבש פלט מובנה ב-5 חלקים:
1. **בניית הדמות**: שם, גיל, מוצא, רקע מקצועי ופרופיל מנהיגותי.
2. **טביעת אצבע אידיאולוגית**: 10 עקרונות יסוד + דירוג כמותי (0–100) של 10 ערכי יסוד עם נימוק.
3. **סדרי עדיפויות (Trade-offs)**: בחירת 3 תחומים בראש סדר העדיפויות והסבר על קיצוצים בתחומים אחרים.
4. **מצע אופרטיבי**: תוכניות עבודה מעשיות ל-9 תחומי ממשל. 3 תחומי העדיפות כוללים **צעד ראשון ב-100 ימים**, **יעד לשנתיים** ו-**KPI מדיד**.
5. **ביקורת עצמית**: ניסוח "הטיעון החזק ביותר נגד המצע שלי" ומענה נגדי.

## 🌟 תכונות מרכזיות באתר

- 🎴 **כרטיסי מועמדים דינמיים**: תצוגה מרהיבה של פרופיל המועמד, תמצית החזון, תגיות עדיפות, ותגרת ערכים (Radar Chart).
- ⚖️ **השוואה ראש בראש (Side-by-Side)**: השוואת 2–3 מודלים במקביל לפי תחומי מדיניות וטבלת ערכים כמותית.
- 🛡️ **אגרגטור סוגיות מדיניות**: מעבר בין 9 תחומי הממשל לצפייה מרוכזת בפתרונות של כל המודלים.
- 🗳️ **סקר הציבור 2026**: הצבעה בלייב למועמד המועדף עם התפלגות קולות בזמן אמת.
- 🛠️ **Dev Studio (מצב פיתוח)**:
  - חיבור ל-OpenRouter API.
  - טעינה וסינון דינמי של רשימת המודלים מתוך ה-OpenAPI Spec (`/api/v1/models`).
  - בדיקת תמיכה אוטומטית ב-**Grounding** (חיפוש בזמן אמת) ומניעת הפעלת חיפוש במודלים שאינם תומכים בכך.

## 🚀 הרצה מקומית

```bash
# 1. שכפל את המאגר

# 2. כנס לתיקיית הפרויקט
cd ailections

# 3. התקן תלויות
npm install

# 4. הרץ שרת פיתוח מקומי
npm run dev
```
